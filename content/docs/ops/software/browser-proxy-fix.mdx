---
title: 浏览器内网无法上网与代理异常修复
description: 针对开启 VPN 后导致 OA 审批、邮件系统或内部打印机管理页面打不开的解决指南。
---

如果电脑出现“QQ/微信在线，但浏览器任何内网系统（如 OA、企业邮箱、打印机 Web 页面）均报错或提示 ERR_PROXY_CONNECTION_FAILED”，通常是系统残留的代理服务器拦截了内网局域网连接。

---

## 解决步骤（Windows 11 / Windows 10）

1. 点击桌面左下角 **「开始」** 菜单，进入 **「设置」**（齿轮图标，或按 `Win + I`）；
2. 点击进入 **「网络和 Internet」**；
3. 在选项菜单中点击 **「代理 (Proxy)」**；
4. 依次检查并调整右侧三项配置：
   - **自动检测设置**：拨至 **`关 (Off)`**（除非网管有特殊下发脚本）；
   - **使用安装脚本 (PAC 脚本)**：拨至 **`关 (Off)`**；
   - **手动设置代理 (代理服务器)**：点击编辑，将「使用代理服务器」拨至 **`关 (Off)`**；
5. 点击 **「保存 / 应用」**；
6. 重新刷新浏览器网页，内网系统即可秒开。
