---

## 操作步骤

1. 确保电脑已连接专线网络或开启了 VPN 客户端；
2. 点击谷歌浏览器右上角三个点，选择「扩展程序」➔ **「访问 Chrome 应用商店」**：

![访问Chrome应用商店](/images/ops/image73.png)

3. 在应用商店的搜索框中输入自己需要的扩展名称（例如 `Screenshot Tool`）：

![搜索所需扩展名称](/images/ops/image74.png)

4. 点击蓝色的 **「添加至 Chrome」** 按钮：

![点击添加至Chrome](/images/ops/image75.png)

5. 安装成功后，点开浏览器右上角设置里的扩展程序，就能看到并管理刚刚添加的插件工具：

![扩展程序列表中查看](/images/ops/image76.png)
