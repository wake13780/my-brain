---

## 操作步骤

1. **准备网络环境**：确保电脑已连接专线网络或开启了 VPN 客户端；
2. **访问应用商店**：
   - 打开 Chrome 浏览器，点击右上角 **三个点**；
   - 鼠标悬停在 **「扩展程序」** ➔ 点击 **「访问 Chrome 应用商店」**；
3. **检索并安装扩展**：
   - 在左上方搜索框中输入你需要的扩展名称（例如 `Screenshot Tool`、`沉浸式翻译` 等）；
   - 进入详情页面后，确认评分与开发者信息，点击蓝色的 **「添加至 Chrome」** 按钮；
   - 弹出权限提示时，点击「添加扩展程序」；
4. **管理与固定图标**：
   - 点击浏览器右上角拼图图标（扩展程序），点击对应插件右侧的“图钉”图标，即可将常用功能直接固定在浏览器工具栏。
