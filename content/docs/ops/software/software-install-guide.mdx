办公电脑出现大量广告弹窗、流氓全家桶，90% 都是由于员工在非官方下载站乱点“高速下载”或未看清捆绑安装协议导致。

---

## 第一步：认准官方下载源头

1. **核心原则**：**官方优先，拒绝第三方下载器**；
2. 在百度、Edge 搜索软件名称时，必须认准带有 **`官方`** 或 **`官网`** 蓝底认证标志的链接；
3. 严禁点击带有“高速下载器”、“某某安全下载”、“绿色下载站”等具有误导性质的广告位；
4. 下载保存位置：统一放在桌面的临时安装包文件夹，安装完毕后随手删除。

---

## 第二步：安装向导执行（避坑三大准则）

1. **盘符科学规划（C 改 D）**：
   - 默认路径通常形如 `C:\Program Files\...`；
   - **运维建议**：如果电脑 C 盘空间紧张，点击「自定义安装 / 浏览 (Browse)」，**仅将开头的盘符字母 `C` 手动更改为 `D`**（即 `D:\Program Files\...`），保持后续目录结构不变。
2. **严查隐藏勾选项（防流氓全家桶）**：
   在点击“下一步”时，务必仔细检查界面底端极小字体的勾选项：
   - ❌ **开机自动启动**：除钉钉、企业微信、输入法外，其余软件一律取消勾选；
   - ❌ **安装 XX 杀毒软件 / XX 极速浏览器 / XX 桌面壁纸**：务必全部取消勾选！
3. **完成清理**：
   安装结束后取消勾选“立即体验附带软件”，并删除桌面上的 `.exe` 原始安装包。
