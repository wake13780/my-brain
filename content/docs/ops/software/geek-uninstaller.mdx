Windows 传统的控制面板卸载往往会残留大量注册表项和 AppData 垃圾文件。IT 运维推荐统一使用 **Geek Uninstaller** 绿色工具。

---

## 操作步骤

1. **下载便携版软件**：
   - 访问 Geek 官方网站（或使用 IT 知识库共享目录中的安装包）；
   - 点击 Download 下载免费版 `.zip` 压缩包，解压后得到单个绿色的 `geek.exe`；
2. **运行与筛选**：
   - 双击打开 `geek.exe`，界面按字母或安装日期列出本机安装的所有软件；
3. **彻底卸载**：
   - 鼠标右键单击需要清除的目标软件，选择 **「卸载 (Uninstall)」**；
   - 若遇到无法正常卸载的流氓软件，直接右键选择 **「强制删除 (Force Removal)」**；
4. **清理深层注册表与残留文件**：
   - 官方卸载程序走完后，Geek 会自动扫描深度残留；
   - 弹出「发现残留痕迹！」窗口，自动勾选所有注册表项（HKEY_CURRENT_USER/MACHINE）与残留文件夹；
   - 点击 **「完成」**，几秒内彻底粉碎一切残渣。
