---
title: Chrome 浏览器书签备份与导入教程
description: 换电脑、重装系统或调换岗位时，快速导出与恢复 Chrome 常用网页书签。
---

为避免设备更换或系统重置导致长期积累的工作常用网址丢失，请定期按以下规范进行书签备份：

---

## 一、导出书签备份至桌面

1. 打开 Google Chrome 浏览器；
2. 点击右上角 **三个竖点 (更多选项)**；
3. 鼠标悬停在 **「书签和清单」** ➔ 点击 **「书签管理器」**（或直接按快捷键 `Ctrl + Shift + O`）；
4. 进入书签管理器页面后，点击右上角（蓝色搜索栏下方）的 **三个竖点**；
5. 在下拉菜单中点击 **「导出书签」**；
6. 选择保存路径为 **「桌面」**，文件名为形如 `bookmarks_2026_xx_xx.html` 的 HTML 文件。

---

## 二、新设备导入书签恢复

1. 在新电脑或重装好的系统上打开 Chrome；
2. 同样点击右上角三个点 ➔ **「书签和清单」➔「书签管理器」**；
3. 点击右侧三个竖点，选择 **「导入书签」**；
4. 找到并选择桌面上备份好的 `.html` 书签文件并打开；
5. 导入成功后，所有的书签栏、文件夹与常用网站将完整复原。
