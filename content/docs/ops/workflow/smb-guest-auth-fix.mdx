| 适用范围 | 说明 |
| :--- | :--- |
| **Windows 10/11 专业版 / 企业版** | 直接按本文组策略操作 |
| **Windows 10/11 家庭版** | 需先通过脚本开启本地组策略编辑器 |

---

## 问题现象

客户端尝试访问局域网共享（如 `\\192.168.x.x`）时，Windows 弹出红叉报错拦截弹窗：
> *"你不能访问此共享文件夹，因为你组织的安全策略阻止未经身份验证的来宾访问。这些策略有助于保护你的电脑免受网络上不安全或恶意设备的侵害。"*

---

## 解决操作步骤

### 1. 打开本地组策略编辑器
按键盘快捷键 **`Win + R`** ➔ 输入 **`gpedit.msc`** ➔ 按回车。

### 2. 定位到 Lanman 工作站策略节点
在左侧控制台树中逐层展开以下路径：
```
计算机配置
  └── 管理模板
        └── 网络
              └── Lanman 工作站
```

### 3. 启用“不安全的来宾登录”
1. 在右侧窗格策略列表中，找到名为 **「启用不安全的来宾登录 (Enable insecure guest logons)」** 的条目；
2. 鼠标双击打开该策略；
3. 将配置状态由“未配置”修改为 **「已启用 (Enabled)」**；
4. 点击「确定」并关闭组策略编辑器。

### 4. 强制刷新策略使其立即生效
以管理员身份打开 CMD 命令提示符，执行以下策略刷新命令：

```cmd
gpupdate /force
```

看到输出提示 **“计算机策略更新成功完成”** 即代表立即生效，**无需重启计算机**，再次打开 `\\IP` 即可顺畅进入共享！
