为确保固定资产账实相符，新员工入职或老员工调配新设备时，必须通过钉钉固定资产系统完成线上扫码绑定。

---

## 领用标准 8 步图解流程

| 步骤 | 操作要点 |
| :--- | :--- |
| **1** | 用手机扫描显示屏背后的“二维码”进入资产详情页面（注意必须使用个人企业账号） |
| **2** | 点击下方的“资产管理”按钮 |
| **3** | 确认所属公司主体（根据下方主体对应表找到自己中心对应的主体） |
| **4** | 备注栏务必规范填写：“**本人领用**” |
| **5** | 点击“+ 添加”主机设备（用手机扫描机箱或笔记本背部的二维码） |
| **6** | 选择业务类型：“**申领**” |
| **7** | 点击“提交审批” |
| **8** | 审批通过后在设备领用表上登记“是”已完成 |
