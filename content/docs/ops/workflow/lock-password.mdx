---
title: Windows 锁屏与系统开机密码修改教程
description: 四种修改 Windows 11/10 登录与锁屏密码的标准方法（图形设置、控制面板、命令行、快捷键）。
---

为保障个人工位电脑数据安全，建议新员工入职后第一时间修改初始开机密码，并定期轮换：

---

## 方法一：通过系统设置修改（最常用）

1. 按快捷键 `Win + I` 打开「设置」；
2. 点击左侧导航栏的 **「账户 (Accounts)」**；
3. 选择 **「登录选项 (Sign-in options)」**；
4. 展开 **「密码」** 栏目，点击 **「更改」**；
5. 输入当前正在使用的旧密码验证身份；
6. 根据系统提示输入新密码、确认新密码及密码提示，点击完成。

---

## 方法二：通过快捷键修改（最快捷）

1. 在电脑任意界面（包括锁屏状态下），同时按下组合键 **`Ctrl + Alt + Del`**；
2. 在安全选项列表中点击 **「更改密码」**；
3. 输入旧密码以及两次新密码，回车确认即可生效。

---

## 方法三：通过管理员命令行快速重置（忘记老密码时）

若具备管理员权限，无需输入旧密码即可直接强制覆盖新密码：

1. 按 `Win + X`，选择 **「终端管理员」** 或 **「Windows PowerShell (管理员)」**；
2. 运行以下命令：
   ```cmd
   net user 你的本地用户名 新密码
   ```
   *例如：`net user Emin Admin@2026`*
3. 按回车确认，提示“命令成功完成”即表示密码已被强制重置。

---

## 方法四：通过控制面板修改

1. 按 `Win + R` 输入 `control` 并打开控制面板；
2. 点击 **「用户账户」➔「更改账户类型」**；
3. 点击当前账户，选择 **「更改密码」**，按向导完成修改。
