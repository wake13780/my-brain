title: 部门专用共享访问实战指引 (以品质数据看板为例)
description: 典型业务部门专属共享服务器（172.21.26.69）的凭据预存与桌面映射实操规范。
---

在公司日常运转中，业务部门（如品质、招商、物流、面料等）常在专用文件主机上存放核心看板数据。以下以典型部门专用共享为例梳理标准化访问流程：

---

## 阶段一：在凭据管理器中录入部门专属账号

1. 按快捷键 `Win + R` 呼出运行窗口，输入 `control` 打开控制面板；
2. 依次点击进入 **「用户账户」➔「凭据管理器」**；
3. 选择 **「Windows 凭据」**；
4. 点击「添加 Windows 凭据」：
   - **Internet 地址或网络地址**：输入目标服务器 IP `172.21.26.69`（若已有旧条目先点击删除重新录入）；
   - **用户名**：输入该部门分配的专属账户名（如 `pz`）；
   - **密码**：输入对应的认证密码；
5. 点击确定保存退出。

---

## 阶段二：访问共享与创建桌面快捷方式

1. 按键盘上的快捷键 **`Win + R`**；
2. 输入 `\\172.21.26.69` 并回车；
3. 验证通过后直接进入共享文件列表（包含：`26年交付&品质&打版数据看板`、`面料`、`物流`、`招商`、`更新文件` 等）；
4. 鼠标右键点击核心文件夹，选择 **「发送到 ➔ 桌面快捷方式」**，后续可在桌面直接秒级双击访问。
