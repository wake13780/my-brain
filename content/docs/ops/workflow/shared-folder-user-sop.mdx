在公司日常运转中，业务部门（如品质、招商、物流、面料等）常在专用文件主机上存放核心看板数据。以下以典型部门专用共享为例梳理标准化访问流程：

---

## 阶段一：在 Windows 凭据管理器中录入部门专属账号

1. 按 `Win + R` 键，输入 `control`，然后点击回车：

![Win+R输入control](/images/ops/image55.png)

2. 点击打开 **「用户账户」**：

![点击用户账户](/images/ops/image56.png)

3. 点击 **「管理 Windows 凭据」**：

![点击管理Windows凭据](/images/ops/image57.png)

4. 点击下方的 **「添加 Windows 凭据」**：

![点击添加Windows凭据](/images/ops/image58.png)

5. 进入添加凭据页面：

![添加凭据页面](/images/ops/image59.png)

6. 第一行输入目标服务器 IP `172.21.26.69`（如果原来有这个名称的旧条目，先点击删除）：

![输入服务器IP地址](/images/ops/image89.png)

7. 输入分配的用户名（例如 `pz`）和对应密码，然后确定保存退出：

![输入账号密码](/images/ops/image90.png)

---

## 阶段二：访问共享与创建快捷方式

1. 按键盘快捷键 **`Win + R`**；
2. 输入 `\\172.21.26.69` 然后点击回车：
   - 弹窗提示时输入对应的用户名与密码，**务必勾选「记住我的凭据」**；
3. 确认后即可进入共享目录（包含 `26年交付&品质&打版数据看板`、`面料`、`物流`、`招商`、`更新文件` 等文件夹）：

![进入部门共享页面](/images/ops/image91.png)

4. 鼠标右击目标核心文件夹，选择创建快捷方式放到桌面，后续即可双击秒开。
