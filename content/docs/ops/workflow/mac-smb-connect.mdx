苹果电脑（MacBook / Mac mini / iMac）挂载 Windows 共享或企业 NAS 共享的标准操作步骤如下：

---

## 操作步骤

1. **打开访达**：
   在 Mac 桌面下方的 Dock 栏中，点击最左侧笑脸图标的 **「访达 (Finder)」**；
2. **唤醒连接服务器窗口 (`Command + K`)**：
   在桌面状态下，同时按下键盘上的快捷键：
   ```
   Command + K
   ```
3. **输入服务器 SMB 网络路径**：
   在弹出的「连接服务器」地址输入框中输入：
   ```
   smb://目标服务器IP
   ```
   *(例如：`smb://172.21.11.221`)*，然后点击右下角的 **「连接」** 按钮；
4. **身份认证与密码保存**：
   - 连接身份单选框中选择 **「注册用户」**；
   - **名称**：输入分配给你的共享账号；
   - **密码**：输入对应的密码；
   - 务必勾选 **「在我的钥匙串中记住此密码」**（下次开机自动免密挂载）；
5. 点击「连接」，选择挂载的目标共享卷（如资料盘、公共部），即可像访问本地硬盘一样无缝操作文件。
