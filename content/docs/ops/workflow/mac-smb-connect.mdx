苹果电脑（MacBook / Mac mini / iMac）挂载 Windows 共享或企业 NAS 共享的标准操作步骤如下：

---

## 操作步骤

1. 在 Mac 桌面上点击底部 Dock 导航栏最左侧的 **「访达 (Finder)」**：

![点击访达](/images/ops/image86.png)

2. 进入访达后，按键盘快捷键 **`Command + K`** 呼出「连接服务器」窗口：
   - 在地址栏输入 `smb://` 加上目标服务器的 IP 地址（例如：`smb://172.21.11.221`）；
   - 然后点击右下角蓝色的 **「连接」**：

![Command+K连接服务器](/images/ops/image87.png)

3. 弹出认证弹窗后：
   - 连接身份勾选 **「注册用户」**；
   - 输入分配给你的用户名和密码；
   - **务必勾选「在我的钥匙串中记住此密码」**；
   - 点击「连接」：

![输入账号密码并记住密码](/images/ops/image88.png)

4. 挂载成功后，即可在访达边栏像本地硬盘一样无缝双向存取文件。
