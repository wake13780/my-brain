---
title: 双凭证同时访问同一个共享服务器高阶技巧
description: 利用 Windows hosts 别名与 net use 机制突破同一客户端无法使用多个账号连接同一 IP 共享的系统限制。
---

Windows 操作系统原生存在一项安全限制：**同一个客户端 Windows 电脑，不允许使用两个不同的用户凭据（账号密码）同时连接同一台服务器的 IP 地址**。

当同一个员工既需要使用账号 A 访问“前期部”文件夹，又需要使用账号 B 访问“财务部”文件夹时，传统的连接方式会直接报错“不允许一个用户使用一个以上用户名与一个服务器或共享资源的多重连接”。

---

## 解决方案：通过 HOSTS 别名伪装成两台不同服务器

通过在本地 hosts 文件中为同一物理 IP 赋予两个不同的别名（Hostname），让 Windows 误以为访问的是两台完全不同的机器：

### 第一步：以管理员身份编辑 hosts 文件
1. 按 `Win + S` 搜索「记事本」，**鼠标右键点击记事本，选择「以管理员身份运行」**；
2. 在记事本中点击文件 ➔ 打开，路径定位到：
   ```
   C:\Windows\System32\drivers\etc\hosts
   ```
3. 在文件末尾添加以下别名映射（假设共享服务器 IP 为 `172.21.11.221`）：
   ```
   172.21.11.221 server-a
   172.21.11.221 server-b
   ```
4. 保存并关闭记事本。

---

### 第二步：使用 net use 分别绑定两套凭据
以管理员身份打开 CMD 命令提示符，分别执行以下命令：

```cmd
# 凭据 A 绑定到别名 server-a
net use \\server-a\前期部 /user:账号A 密码A

# 凭据 B 绑定到别名 server-b
net use \\server-b\财务部 /user:账号B 密码B
```

---

### 第三步：日常访问
日常使用时，按 `Win + R`：
- 输入 `\\server-a` ➔ 即可无缝进入账号 A 权限下的部门文件；
- 输入 `\\server-b` ➔ 即可无缝进入账号 B 权限下的财务部门文件；
两者彻底并存，永不冲突互斥！
