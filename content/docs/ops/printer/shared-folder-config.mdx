---

## 操作步骤

1. 在桌面新建一个文件夹，可以命名为自己喜欢的名字（例如 `share`）；
2. 右击该文件夹，点击进入 **「属性」**：

![文件夹右键选择属性](/images/ops/image48.png)

3. 进入属性后点击 **「共享」** 选项卡，点击「共享(S)...」按钮，添加要共享的用户（例如 `Guest` 或 `Everyone`）：

![添加共享用户Guest](/images/ops/image49.png)

4. 选择赋予的权限级别（例如 **「读取」** 或「读取/写入」），然后点击「共享」：

![权限级别选择读取](/images/ops/image50.png)

5. 回到属性页面，点击下方的 **「高级共享(D)...」**，勾选 **「共享此文件夹」**：

![高级共享勾选共享此文件夹](/images/ops/image51.png)

6. 然后点击下方的 **「权限(P)」** 按钮，点击「添加(D)...」：

![点击权限添加用户](/images/ops/image52.png)

7. 输入要添加的用户名 `guest`，点击右侧的 **「检查名称」**，系统确认无误后点击确定：

![输入guest点击检查名称](/images/ops/image53.png)

8. 选中添加的 Guest 用户，在下方勾选对应的权限（如允许读取）：

![勾选读取权限](/images/ops/image54.png)

9. 添加完成后一直点击确定退出保存即可。
