---

## 操作步骤

1. 在桌面或常用数据盘新建文件夹，命名为你的共享名称（例如 `share`）；
2. 鼠标右击该文件夹，选择 **「属性」**；
3. 切换至 **「共享」** 选项卡，点击上方 **「共享(S)...」**；
4. 在下拉用户选择栏中选择或输入目标共享用户（如 `Guest` 或 `Everyone`），点击「添加」；
5. 在下方列表中调整其权限级别（如根据需要选择 **「读取」** 或 **「读取/写入」**），点击右下角「共享」；
6. 回到属性页面，点击下方的 **「高级共享(D)...」**；
7. 勾选 **「共享此文件夹」**；
8. 点击下方的 **「权限(P)」** 按钮：
   - 点击「添加」，输入指定用户名（如 `guest`），点击「检查名称」确认后确定；
   - 在下方勾选赋予的权限（完全控制/更改/读取）；
9. 依次点击确定退出并保存应用。
