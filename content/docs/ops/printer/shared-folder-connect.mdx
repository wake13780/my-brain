当其他员工或服务器共享了文件夹后，客户端电脑按以下流程建立持久化连接：

---

## 阶段一：在 Windows 凭据管理器中预存密码

1. 按键盘上的快捷键 `Win + R`，输入 `control`，点击回车：

![Win+R输入control](/images/ops/image55.png)

2. 点击打开 **「用户账户」**：

![控制面板点击用户账户](/images/ops/image56.png)

3. 点击 **「管理 Windows 凭据」**：

![点击管理Windows凭据](/images/ops/image57.png)

4. 点击下方的 **「添加 Windows 凭据」** 链接：

![添加Windows凭据链接](/images/ops/image58.png)

5. 进入添加凭据页面：

![添加凭据页面](/images/ops/image59.png)

6. 第一行可以填入目标共享主机的计算机名（可在 Windows 设置系统页面查看计算机名）：

![系统页面查看计算机名](/images/ops/image60.png)
![填入计算机名称](/images/ops/image61.png)

7. 或者直接输入共享服务器的局域网 IP（例如 `192.168.1.230`），填入账号（例如 `MGZJ`）和密码并保存退出：

![编辑凭据输入IP与账号](/images/ops/image62.png)

---

## 阶段二：通过 Win + R 挂载访问

1. 查看本机 IP 或服务器 IP（`Win + R` 输入 `cmd`，跳转后再输入 `ipconfig` 查询）：

![输入ipconfig查询IP](/images/ops/image63.png)

2. 按键盘上的快捷键 **`Win + R`**，输入 `\\` 加上服务器 IP（例如 `\\192.168.1.230`）并回车：
   - 弹窗提示输入网络凭据时，输入对应的账号密码；
   - **务必勾选「记住我的凭据」**！

![输入网络凭据并勾选记住](/images/ops/image64.png)

3. 确认后即可进入共享目录（如后期部、前期部、旧文件服务器迁移数据等）：

![进入局域网共享目录](/images/ops/image65.png)

4. 右击常用文件夹，选择创建快捷方式放到桌面，后续即可直接双击秒开。
