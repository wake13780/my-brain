当其他员工或服务器共享了文件夹后，客户端电脑按以下流程建立持久化连接：

---

## 阶段一：在 Windows 凭据管理器中预存密码

为了避免每次开机或断网重连时反复弹窗报错，必须先在凭据中心存入认证信息：

1. 按 `Win + R` 键，输入 `control` 并回车打开经典控制面板；
2. 点击 **「用户账户」➔「凭据管理器」**；
3. 选择右侧的 **「Windows 凭据」**；
4. 点击下方的 **「添加 Windows 凭据」** 链接；
5. 依次输入：
   - **Internet 地址或网络地址**：输入共享主机的局域网 IP（例如 `192.168.1.230` 或主机名）
   - **用户名**：目标主机分配的共享账户名（例如 `MGZJ`）
   - **密码**：对应的共享密码
6. 点击确定保存。

---

## 阶段二：通过 Win + R 挂载访问

1. 按键盘上的快捷键 **`Win + R`**；
2. 在运行窗口输入 `\\` 加上共享服务器的 IP：
   ```
   \\192.168.1.230
   ```
3. 点击回车；若弹出认证对话框，输入对应账号密码并**务必勾选「记住我的凭据」**；
4. 验证成功后，即可进入共享目录（如后期部、前期部、迁移数据等）；
5. 选中常用文件夹，点击鼠标右键 ➔ **「显示更多选项」➔「发送到」➔「桌面快捷方式」**，后续双击桌面图标即可秒开。
