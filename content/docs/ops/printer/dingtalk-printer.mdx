企业采用钉钉云打印解决方案，员工电脑无需单独寻找各种型号复杂驱动，通过统一云插件即可发起跨楼层打印。

---

## 操作步骤

1. **运行安装插件**：
   双击运行企业提供的 `cloud_printer_plugin.exe` 安装文件，等待安装进度条跑完（耗时约 2~5 秒）。
2. **在办公软件中选择云打印机**：
   - 打开 WPS 或 Microsoft Word；
   - 按 `Ctrl + P` 呼出打印对话框；
   - 打印机名称下拉列表中选择 **「钉钉智能云打印机 (DingDingPort)」**；
3. **选择所在工位区域的目标设备**：
   - 在弹出的钉钉打印浮窗中，选择对应所属公司主体和所在楼层区域的设备（例如：`广州沃芙科技 - 阿道夫十楼人力中心打印机0837 - IM C3000`）；
   - 设置纸张尺寸（A4/A3）、打印份数、单双面及色彩模式（黑白/彩色）；
4. 点击确认即可完成云打印。
