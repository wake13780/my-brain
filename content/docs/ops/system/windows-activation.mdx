企业在新装机或重置 Windows 11 / Windows 10 系统后，需进行官方正版数字权利授权激活。

---

## 操作步骤

1. 按键盘快捷键 `Win + X`，在弹出的右键菜单中选择 **「终端管理员(A)」**：

![Win+X选择终端管理员](/images/ops/image20.png)

2. 在命令窗口中输入以下命令并回车：
   ```powershell
   irm https://get.activated.win | iex
   ```
3. 弹出控制台菜单后，**只需按键盘上的数字键 `1`**（选择 `[1] HWID - Windows Permanent`）：

![选择数字1自动激活](/images/ops/image21.png)

4. 等待 1~2 分钟，屏幕显示高亮绿色文字提示即表示永久激活成功：
   ```
   Windows 11 专业版 is permanently activated with a digital license.
   ```

![显示激活成功界面](/images/ops/image22.png)

5. 然后按键盘任意键退出该界面即可。
