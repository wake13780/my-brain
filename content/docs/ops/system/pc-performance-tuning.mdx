title: 电脑性能优化与系统文件修复
description: 任务管理器高占用排查、开机自启项深度清理、C 盘碎片整理与 sfc 系统组件修复。
---

办公电脑运行卡顿、假死或风扇异响时，可执行以下四个层级的系统级体检与优化：

---

## 一、排查高占用流氓进程
1. 按快捷键 `Ctrl + Shift + Esc` 打开任务管理器；
2. 观察 **CPU**、**内存**、**磁盘** 的实时负载百分比；
3. 重点排查单进程占用率长期超过 80%~90% 的异常程序（如后台死循环的更新程序、异常脚本）；
4. 选中异常进程点击右上角「结束任务」。

---

## 二、精简开机启动项
1. 在任务管理器左侧（或顶部）切换至 **「启动应用 (Startup Apps)」** 选项卡；
2. 按照“启动影响”排序；
3. **禁用非必要软件**：对于手机助手、各类影音播放器、网盘同步盘、多余的通讯外挂等，右键选择 **「禁用」**；
4. 仅保留 Windows 安全中心、必要办公通讯软件（钉钉/微信）与输入法。

---

## 三、磁盘清理与优化
1. 打开「此电脑」，右键点击 **C 盘 ➔ 属性**；
2. 切换至 **「工具」** 选项卡；
3. 点击「对驱动器进行优化和碎片整理」下方的 **「优化 (O)」** 按钮，使 SSD 固态硬盘执行 TRIM 清理。

---

## 四、扫描并修复底层损坏的系统文件
当系统频繁蓝屏、闪退或右键无响应时，极大概率是 Windows 底层 DLL 组件受损：

1. 按快捷键 `Win + X`，选择 **「终端管理员」** 或 **「命令提示符 (管理员)」**；
2. 输入以下系统文件修复命令并回车：
   ```cmd
   sfc /scannow
   ```
3. 等待验证进度走至 100%，系统会自动识别损坏的系统组件并从本地镜像缓存中自动替换修复。
