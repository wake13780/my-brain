在设备需要彻底交接、重装系统或解决无法排除的深层顽疾时，可采用 Windows 原生的重置机制。

---

## 操作步骤

1. 按 `Win + I` 打开电脑设置，在搜索框中搜索 **「恢复」** 或 **「重置」**：

![设置中搜索重置此电脑](/images/ops/image39.png)

2. 点击打开并选中 **「初始化电脑」**：

![点击初始化电脑按钮](/images/ops/image40.png)

3. **选择选项**：为保证干净彻底，选中 **「删除所有内容」**（删除所有个人文件、应用和设置）：

![选中删除所有内容](/images/ops/image41.png)

4. **重新安装方式**：选择 **「本地重新安装」**（从本地设备缓存重新安装 Windows，速度快且不耗费网络）：

![选择本地重新安装](/images/ops/image42.png)

5. 点击下一页，然后再点击「重置」，系统将自动恢复成出厂全新设置，所有旧数据将会被安全清空。
