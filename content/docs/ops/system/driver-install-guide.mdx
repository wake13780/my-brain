## 阶段一：确认精确硬件型号与序列号

在前往制造商官网前，务必先查询准确的设备标识：

| 硬件类型 | 查询方式 | 识别凭证 |
| :--- | :--- | :--- |
| **品牌机 / 笔记本** (联想/戴尔/HP) | 查看机身底部或机箱侧面的出厂标签 | **SN 序列号** 或 **Service Tag** |
| **组装台式机 (主板)** | 按 `Win + R` 输入 `msinfo32` 确认 | 查看 **「基板产品」**（即主板型号） |
| **独立显卡** | 右键「此电脑」➔ 管理 ➔ 设备管理器 | 查看 **「显示适配器」** 下的型号 |
| **企业网络打印机** | 查看打印机机身面板或液晶屏信息 | 完整产品型号（如 HP LaserJet M1005） |

---

## 阶段二：从官网下载对应版本

- **核心必装驱动（优先安装）**：
  1. 芯片组驱动 (Chipset)
  2. 网卡驱动 (Wireless LAN / Ethernet)
  3. 显卡驱动 (Graphics / VGA)
- **外设与功能类驱动**：
  - 音频驱动 (Audio)、蓝牙驱动 (Bluetooth)、触摸板驱动 (Touchpad)。
- **格式选择**：优先下载厂商官方提供的 `.exe` 或 `.msi` 一键安装包。

---

## 阶段三：标准安装流程与避坑指南

1. **运行安装**：双击下载好的 `.exe` 驱动安装包，若弹出“用户账户控制 (UAC)”提示，点击「是」；
2. **保持默认路径**：严禁更改驱动内部释放路径，默认保持在 `C:\...` 即可；
3. **安装现象说明**：
   - 安装显卡驱动时，屏幕出现 **数次短暂黑屏或闪烁** 属于正常现象，绝对不可断电或强制关机；
   - 安装声卡驱动后，系统音量可能会暂时被重置；
4. **重启生效**：驱动安装完成后，必须点击提示框中的 **「立即重启计算机」**，以便驱动完成内核挂载。
