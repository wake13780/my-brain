---
title: C 盘空间扩容教程
description: 利用 Windows 原生磁盘管理器安全调整分区布局，扩展系统 C 盘容量。
---

办公电脑长期使用后，系统更新缓存、微信/钉钉数据会导致 C 盘飘红报警。可通过相邻分区调整为 C 盘扩展容量。

> [!CAUTION] 数据备份预警
> 在磁盘管理中对 D 盘进行格式化前，**务必先将 D 盘数据完整备份**！

---

## 操作步骤

1. 在开始菜单搜索 **「计算机管理」**，进入计算机管理后选择 **「磁盘管理」**：

![计算机管理中选择磁盘管理](/images/ops/image23.png)

2. 在磁盘管理中鼠标右键单击 **D 盘**，选择 **「格式化」**（或删除卷，注意先备份好 D 盘数据）：

![右键单击D盘选择格式化](/images/ops/image24.png)

3. 删除/格式化成功后，在磁盘管理中鼠标右键单击 **C 盘**，选择 **「扩展卷(X)...」**：

![右键单击C盘选择扩展卷](/images/ops/image25.png)

4. 根据扩展卷向导一直点击「下一步」进行操作，即可扩展 C 盘成功！
