---
title: C 盘空间扩容教程
description: 利用 Windows 原生磁盘管理器安全调整分区布局，扩展系统 C 盘容量。
---

办公电脑长期使用后，系统更新缓存、微信/钉钉数据会导致 C 盘飘红报警。可通过相邻分区调整为 C 盘扩展容量。

> [!CAUTION] 数据备份预警
> 在对 D 盘进行格式化或删除前，**必须先将 D 盘中的重要工作文件、代码及个人资料完整备份**至移动硬盘或企业网盘！

---

## 操作步骤

1. 按 `Win + S` 搜索并打开 **「计算机管理」**；
2. 在左侧控制台树中选择 **「存储」➔「磁盘管理」**；
3. 查看磁盘 0 的分区布局（C 盘必须与目标扩展空间紧邻）；
4. 鼠标右键单击 D 盘（确保数据已备份）：
   - 选择 **「格式化」** 或 **「删除卷」**；
   - 删除后 D 盘空间将变为“未分配”黑条状态；
5. 鼠标右键单击 **C 盘**，在菜单中选择 **「扩展卷(X)...」**；
6. 弹出「扩展卷向导」后，点击下一步，选择刚刚释放的未分配磁盘空间；
7. 连续点击下一步直至完成，此时即可看到 C 盘容量已成功扩充。
