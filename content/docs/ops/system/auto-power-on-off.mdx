title: 电脑定时自动开机与自动关机设置
description: 硬件 BIOS RTC 闹钟事件定时自动开机 + Windows 任务计划程序定时关机方案。
---

为节省电力并保证每日上班前电脑已完成自检就绪，可统一配置自动开机与定时关机策略。

---

## 一、主板 BIOS 设置定时自动开机

1. **进入 BIOS 界面**：
   电脑开机出现主板品牌 Logo（如微星、华硕、联想）时，连续狂按键盘上的 **`Delete`** 键或 **`F12`** 键进入 BIOS 设置。
2. **定位唤醒事件设置**：
   - 切换到 **「高级设置 (Advanced)」➔「唤醒事件设置 (Wake Up Event Setup)」**；
   - 找到 **「即时(RTC)闹铃唤醒 (Resume By RTC Alarm)」** 并将其更改为 **`允许 (Enabled)`**。
3. **设定开机时间参数**：
   - **日期 (月份) 闹钟**：设置为 `0`（`0` 代表每天都生效）；
   - **闹钟 (时)**：输入开机具体小时（例如设置为 `8` 代表每天早上 8:00 开机）；
   - **闹钟 (分)**：输入 `0`；
   - **闹钟 (秒)**：输入 `0`。
4. **保存退出**：按下键盘上的 **`F10`** 键，选择「保存更改并退出」，电脑重启后即可生效。

---

## 二、Windows 任务计划程序设置定时关机

1. 在 Windows 搜索框中输入 **「任务计划程序」** 并打开；
2. 在右侧「操作」窗格中点击 **「创建基本任务...」**；
3. **名称**：输入 `自动关机`，点击下一步；
4. **触发器**：选择 **「每天」**，设置关机时间（如每天晚上 `21:30:00`）；
5. **操作**：选择 **「启动程序」**，点击下一步；
6. **程序和脚本参数**：
   - **程序或脚本**：输入 `shutdown`
   - **添加参数**：输入 `-s -t 0`（含义为倒计时 0 秒强制关闭操作系统）
7. 点击下一步确认摘要信息，点击 **「完成」** 即可。
