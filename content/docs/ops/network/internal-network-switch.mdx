description: Windows 11/10 以太网适配器 IPv4 静态 IP 与动态 DHCP 自动获取相互切换步骤。
---

产品中心等特殊部门在日常办公中，需要在「专线 VPN 模式（固定内网静态 IP）」与「常规企业内网（自动获取 DHCP）」之间切换。

---

## 一、VPN 状态切换回内网（自动获取 DHCP）

当工作完毕需要使用普通企业内网时，操作步骤如下：

1. 鼠标右击任务栏右下角的 **以太网（网络图标）**，选择「网络和 Internet 设置」；
2. 点击进入 **「以太网」** 属性；
3. 找到「IP 分配」，点击右侧的 **「编辑」** 按钮；
4. 将下拉框中的 **「手动」改为「自动 (DHCP)」**；
5. 点击 **「保存」** 退出，系统将自动重新向路由器申请动态 IP 地址。

---

## 二、内网切换为 VPN 专用静态 IP

当需要接入专用 VPN 专线网络时，需将以太网配置为指定的静态地址：

### 1. 记录本机当前 IP
1. 按快捷键 `Win + R` 打开运行窗口；
2. 输入 `cmd` 并回车；
3. 在命令提示符中输入 `ipconfig`，找到以太网适配器下的 **IPv4 地址**（例如 `172.21.16.73`），记录该地址。

### 2. 配置手动静态参数
1. 鼠标右击右下角以太网图标 ➔ 进入 **「网络和 Internet」** ➔ **「以太网」**；
2. 在「IP 分配」处点击 **「编辑」**；
3. 将下拉选项从「自动」切换为 **「手动」**，并确保开启 **IPv4** 开关；
4. 依次填写以下网络参数：
   - **IP 地址**：填写上方查到的本机真实 IP（例如 `172.21.16.73`）
   - **子网掩码**：`255.255.255.0`
   - **网关**：`172.21.16.254`
   - **首选 DNS**：`172.21.16.254`
   - **DNS over HTTPS**：保持「关」
5. 点击 **「保存」** 即可完成切换。
