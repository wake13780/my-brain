产品中心等特殊部门在日常办公中，需要在「专线 VPN 模式（固定内网静态 IP）」与「常规企业内网（自动获取 DHCP）」之间切换。

---

## 一、VPN 状态切换回内网教程（自动获取 DHCP）

1. 鼠标右击右下角的 **以太网（网络小电脑图标）**：

![右击以太网标志](/images/ops/image10.png)

2. 进入后接着点击 **「以太网」** 属性：

![进入以太网设置](/images/ops/image11.png)

3. 找到 IP 分配，点击右侧的 **「编辑」**：

![点击编辑IP分配](/images/ops/image12.png)

4. 进入后把下拉菜单的 **「手动」改为「自动(DHCP)」**：

![切换为自动DHCP](/images/ops/image13.png)

5. 点击保存退出，即可顺利恢复内网访问。

---

## 二、内网切换为 VPN 静态 IP 教程

1. 同样右击右下角以太网标志 ➔ 点击以太网 ➔ 点击编辑：

![右击以太网标志](/images/ops/image10.png)
![点击编辑IP分配](/images/ops/image12.png)

2. 进入后把「自动」改为 **「手动」**，开启 IPv4 开关，输入以下参数（除了 IP 地址）：
   - 子网掩码：`255.255.255.0`
   - 网关：`172.21.16.254`
   - 首选 DNS：`172.21.16.254`
   - DNS over HTTPS：保持「关」

![手动配置IPv4参数](/images/ops/image14.png)

### 本机真实 IP 地址查看方法：
1. 按键盘快捷键 `Win + R`，输入 `cmd`，然后点击确定：

![Win+R输入cmd](/images/ops/image15.png)

2. 确定后输入 `ipconfig`，找到以太网适配器下的 **IPv4 地址**（例如 `172.21.16.73`）：

![输入ipconfig查询IP](/images/ops/image16.png)

3. 将查出的真实 IP 输入到第 2 步的 IP 地址框中：

![输入对应IP地址](/images/ops/image17.png)

4. 点击保存退出即可。
