---
title: 网络连通性快速排查指南 (SOP)
description: 遵循“物理层 ➔ 协议层 ➔ 应用层”标准化顺序，秒级定位电脑无法上网问题。
---

“电脑网络不通”是桌面运维中最常见的日常工单。为提高排障效率，必须严格按照标准化流水线逐级排查：

---

## 阶段一：物理层检查（硬件连接）
1. **网线状态**：检查机箱后网口或拓展坞网线是否插紧，确认网口指示灯是否正常绿色常亮/橙色闪烁。
2. **Wi-Fi 开关**：若是笔记本，确认无线网络开关或飞行模式是否被误触关闭。

---

## 阶段二：协议层与 IP 地址检查
1. 按下快捷键 `Win + R`，输入 `cmd` 并回车；
2. 输入 `ipconfig` 检查当前适配器获取到的 IPv4 地址：
   - ⚠️ 若显示 `169.254.x.x`，说明本地 DHCP 获取失败，未分配到有效局域网 IP。
3. **重新申请 IP 租约**：
   ```cmd
   ipconfig /release
   ipconfig /renew
   ```

---

## 阶段三：网络连通性逐级探测 (Ping 测试)
按照由近及远的顺序在 CMD 中执行：

1. **测试本地网卡协议栈**：
   ```cmd
   ping 127.0.0.1
   ```
   *若无法 ping 通，说明本地 TCP/IP 协议栈或网卡驱动损坏。*

2. **测试局域网网关连通性**：
   ```cmd
   ping 172.21.16.254   # 替换为你实际的默认网关
   ```
   *若能通，说明局域网交换机通信正常；若不通，检查网线、VLAN 或交换机。*

3. **测试公网 IP 连通性（避开 DNS）**：
   ```cmd
   ping 8.8.8.8
   ping 114.114.114.114
   ```

4. **测试公网域名解析（DNS 校验）**：
   ```cmd
   ping www.baidu.com
   ```
   *若 ping 8.8.8.8 正常但 ping 域名失败，说明 DNS 异常。*

---

## 阶段四：DNS 缓存刷新
当出现“QQ/微信能发消息，但浏览器所有网页打不开”时，执行以下命令清空本地 DNS 解析缓存：

```cmd
ipconfig /flushdns
```
同时按手册教程检查浏览器是否残留了未关闭的代理服务器设置。
