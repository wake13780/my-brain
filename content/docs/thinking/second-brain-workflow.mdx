人类大脑的设计初衷是**产生想法**，而不是**储存信息**。构建「第二大脑（Second Brain）」的目标，是将零散的记忆与灵感外包给结构化的数字系统，从而释放注意力，聚焦于深度创造。

---

## 一、CODE 认知处理模型

Tiago Forte 提出的 CODE 框架为数字知识管理提供了清晰的流水线：

1. **Capture（捕获）**：只保留引起心智共鸣（Resonate）的少数核心信息。
2. **Organize（组织）**：按行动导向（Actionability）而非来源进行分类（如 PARA 架构）。
3. **Distill（提炼）**：通过渐进式总结（Progressive Summarization）找出本质。
4. **Express（表达）**：输出是最好的内化，将沉淀转化为公开文章、项目或决策依据。

```
       [海量信息]
           │
           ▼
    ┌─────────────┐
    │ 1. Capture  │  --> 过滤杂讯，保留灵感种子
    └──────┬──────┘
           ▼
    ┌─────────────┐
    │ 2. Organize │  --> 按项目/领域分类归档
    └──────┬──────┘
           ▼
    ┌─────────────┐
    │ 3. Distill  │  --> 提炼核心见解与高光观点
    └──────┬──────┘
           ▼
    ┌─────────────┐
    │ 4. Express  │  --> 输出公开知识库与作品
    └─────────────┘
```

## 二、双向链接与概念涌现

传统的树状文件夹分类存在「孤岛效应」，而双向链接（Bi-directional Links）模拟了大脑神经元的网状连接：

- **自下而上（Bottom-Up）生长**：不要提前设计完美繁复的分类，而是从单篇原子笔记开始。
- **概念涌现（Emergence）**：当多个不同领域的笔记通过同一主题标签相互引用时，新的知识拓扑与洞察便自然诞生。
