Web 技术体系在过去几年经历了翻天覆地的演进。从早期的 SPA（单页应用）全量客户端渲染，到现在的服务端组件（RSC）、混合渲染以及边缘计算（Edge Computing），技术选型的决策逻辑发生了根本改变。

---

## 现代 Web 栈的核心要素

### 1. 核心框架与构建体系
- **Next.js (App Router + Turbopack)**：
  - 基于 Rust 重写的 Turbopack 替代 Webpack，冷启动与热更新性能提升近一个数量级。
  - 服务端组件（React Server Components）让首屏无需向客户端发送臃肿的 JS 包，SEO 与加载体验兼得。

### 2. 样式与设计系统
- **Tailwind CSS v4**：
  - 采用全新的 Oxide 引擎，全基于 Rust，编译速度提升 10 倍以上。
  - 原生支持现代 CSS 特性，无需繁重的配置文件，支持现代玻璃态与暗黑霓虹质感。

### 3. 数据层与无服务器基础设施
- **边缘托管与 CDN**：Vercel、Cloudflare Pages、AWS CloudFront。
- **纯文本与本地优先（Local-First）**：将静态 Markdown 与轻量数据库结合，免受复杂云端运维烦恼。
