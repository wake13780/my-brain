## ⚡ 极客使用技巧

- **全局快捷搜索**：在任意页面按下 `Ctrl + K`（Mac 上为 `Cmd + K`）即可秒级呼出全局模糊搜索窗口，输入任何报错代码或故障关键词即可直达对应步骤。
- **自动目录与滚动高亮**：右侧自动生成精准的多级标题目录（TOC），随阅读进度平滑滚动高亮。
- **高清图文对照**：每一篇 SOP 均配有实际操作界面的高清截图标注与参数示范。
