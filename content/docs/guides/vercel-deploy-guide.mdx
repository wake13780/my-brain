通过现代化的 GitOps 工作流，发布上线不需要租用昂贵的云服务器，也不需要配置复杂的 Nginx 反向代理。

---

## 步骤一：推送到 GitHub 仓库

1. 在 [GitHub](https://github.com) 上新建一个空的公共或私有仓库，例如命名为 `my-brain`；
2. 在本地终端进入项目目录执行以下命令：

```bash
cd C:\Users\Emin\.gemini\antigravity\scratch\my-brain

# 初始化 git（若未初始化）
git init

# 添加所有文件并提交
git add .
git commit -m "feat: launch cyber knowledge hub"

# 关联远程仓库（替换为你的 GitHub 仓库地址）
git branch -M main
git remote add origin https://github.com/<你的用户名>/my-brain.git
git push -u origin main
```

---

## 步骤二：在 Vercel 中导入并一键部署

1. 访问 [Vercel 官网 (vercel.com)](https://vercel.com/) 并使用 GitHub 账号直接登录；
2. 点击 **"Add New..."** -> **"Project"**；
3. 在仓库列表中找到刚推送的 `my-brain`，点击 **"Import"**；
4. **Framework Preset** 会自动识别为 **Next.js**，无需修改任何构建命令；
5. 点击 **"Deploy"**！

只需等待大约 1 分钟，Vercel 就会完成构建并分配给你一个专属的全球加速域名（如 `my-brain.vercel.app`）！

---

## 步骤三：绑定个人自定义域名（可选）

如果你有自己的专属独立域名（如 `wiki.yourname.com` 或 `brain.xyz`）：
1. 在 Vercel 项目控制台点击 **Settings** -> **Domains**；
2. 输入你的域名并点击 **Add**；
3. 根据提示在你的域名解析商（如阿里云、腾讯云、Cloudflare 等）添加一条 CNAME 解析记录；
4. Vercel 会自动为你签发**免费的 SSL 证书**（https 访问）。

从此以后，你每次在 Obsidian 中写完新文章，只需执行 `git push`，网站就会自动在几十秒内更新并分发到全球！
