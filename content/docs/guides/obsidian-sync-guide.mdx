本项目的一大核心亮点是 **本地优先与纯粹 Markdown**。你可以完全脱离繁重的后台或网页编辑器，使用你最熟悉的 **Obsidian** 客户端直接写作！

---

## 一、在 Obsidian 中打开项目

1. 打开桌面端 **Obsidian** 应用；
2. 在左侧选择 **「打开文件夹作为仓库 (Open folder as vault)」**；
3. 选择你的项目路径：
   ```
   C:\Users\Emin\.gemini\antigravity\scratch\my-brain\content\docs
   ```
   或者直接选择整个 `my-brain` 根目录。
4. 现在，你就可以在 Obsidian 中看到你的所有知识星系目录了！

---

## 二、编写文章的标准格式

每一篇 Markdown 文章只需在最顶端加上简单的 Frontmatter 元数据即可：

```markdown
---
title: 你的文章标题
description: 简短的一句话描述（用于 SEO 和卡片摘要）
---

这里开始写你的正文内容...
```

### 常用特性语法示例

#### 1. 警告与提示块 (Callout)
你可以直接在文章中使用标准引用或 Fumadocs 的 Callout：

> [!TIP]
> 这是一个技巧提示块，可以用来突出重要观点。

#### 2. 代码高亮
```typescript
function sayHello(name: string): string {
  return `Hello, ${name}! Welcome to My Brain.`;
}
```

#### 3. 数学公式与 Mermaid 流程图
支持嵌入公式与图表，页面会自动渲染成精美的高清矢量图。

## 三、本地实时预览

在终端进入项目根目录：
```bash
npm run dev
```
打开浏览器访问 `http://localhost:3000`，你在 Obsidian 中按 `Ctrl + S` 保存笔记，浏览器就会**毫秒级自动热更新**，立刻呈现最新排版效果！
